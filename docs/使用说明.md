# 🧾 全电发票批量重命名工具

把数电票（全电发票）下载后的超长文件名，一键批量改成 **「购买方公司名—开票金额」** 的清爽格式。

|       | 文件名                                                       |
| ----- | --------------------------------------------------------- |
| ❌ 改之前 | `dzfp_26312000005847746821_深圳某某服务有限公司_20260915110927.pdf` |
| ✅ 改之后 | `上海某某科技有限公司—1060.pdf`                                     |

**支持数电票的全部三种交付格式：PDF / OFD / XML**（含客户发来的 ZIP 压缩包）。  
全程本地运行，发票内容不上传任何服务器。

> **作者：豪崽子**　·　软件左上角版本号旁边就能看到。

### 第 1 步：准备发票

三种方式任选：

| 方式              | 操作                                             |
| --------------- | ---------------------------------------------- |
| 📁 **选文件夹**     | 点右上角 **＋ 选择文件夹**，选中放发票的文件夹                     |
| 🖱️ **拖进来**（最快） | 把**发票文件**、**整个文件夹**、甚至**客户发来的 ZIP 压缩包**直接拖到窗口里 |
| ➕ **单个添加**      | 点 **添加文件**，多选几个 PDF / OFD / XML                |

> 💡 **拖一个文件夹进来 = 自动把里面所有发票都找出来。**  
> 客户发来的总文件夹常常是「子文件夹里还套着压缩包」这种结构，  
> 所以拖文件夹时程序会自动做三件事：
>
> 1. **自动打开「包含子文件夹」**（界面上的开关会跟着亮，不是偷偷改的）
> 2. **把里面所有压缩包就地解开**（解到压缩包旁边的「**原名_解压**」文件夹）
> 3. 压缩包里还套着压缩包也照样往下挖（最多 3 层，防止无限套娃）
>
> 于是像这样的文件夹，拖进去一次就能拿全 5 张：
>
> ```
> 白泽报销--9月/
> ├── 15.李赣.pdf                 ← 根目录的
> ├── 16.蔡盈盈.zip               ← 解开后里面还有 2 张
> └── 新建文件夹/
>     └── 2.杨俊宝.pdf            ← 子文件夹里的
> ```
>
> 已经解压过的**不会重复解、也不会覆盖**你里面的东西（重复拖会提示「先前已解开、直接复用」）。

> 💡 **左上角能看到版本号**（如 `v2.8.4`），窗口标题栏也带着它。  
> 多台电脑上都装了的话，一眼就能知道哪台是新的。

### 第 2 步：在窗口里操作

1. 中间会列出所有发票，自动读出「购买方」和「开票金额」，并显示改后的新名字
2. 点右下角 **开始重命名（N）** → 弹出确认框 → **确认执行**

搞定 ✅

> 💡 不确定效果？先用 **「复制副本」** 模式跑一遍（原文件不动），确认无误再改回「原地重命名」。

> 📌 **同一张票有三个格式怎么办？**  
> 客户经常把 PDF + OFD + XML 一起发来。列表左侧会用  
> <code>PDF</code> / <code>OFD</code> / <code>XML</code> 小标签标出每行是什么格式，  
> 改出来的文件名会**保持原扩展名不变**（OFD 还是 OFD，不会被改成 PDF）。  
> 三份内容一样的票，程序会识别为「票号重复」，按你的「重名规则」自动加序号区分，  
> 不想要的那几行取消勾选即可。

## 🖥️ 二、界面说明

界面分五块，从上到下：

### ① 顶栏

| 按钮       | 作用                        |
| -------- | ------------------------- |
| ＋ 选择文件夹  | 最常用，整个文件夹一起处理（**会换成这个文件夹的票**） |
| 添加文件     | 只处理几个文件时用，可多选。**是累加**：已经有的票不会被冲掉，新选的接在后面 |
| 重新识别     | 换过设置或改过文件后重读一遍            |
| ☐ 包含子文件夹 | 发票分散在多层子文件夹里时勾上（勾上后会立刻重扫） |

> 📌 **v2.6.0 起「添加文件」是累加**：第一次选了几张、第二次再选几张，
> 列表里是**两次的全部**，不会像以前那样把前一批冲掉。
> 同一份文件重复选也不会出现两行（会自动去重）。
> 想重新开始就用「选择文件夹」或「清空列表」。

### ② 命名规则

| 设置        | 说明                                                      |
| --------- | ------------------------------------------------------- |
| **命名规则**  | 默认「购买方名称—发票金额」。点它**勾选**要出现在文件名里的内容，勾了什么、文件名就是什么，顺序还能自己调 |
| **金额格式**  | 智能（`3000` / `1060.50`）、两位小数（`3000.00`）、取整（`3000`）       |
| **处理方式**  | `原地重命名` = 直接改名；`复制副本` = 原文件保留，副本放「重命名输出」文件夹             |
| **按客户归档** | 打开后按购买方公司名自动建子文件夹。配合「原地重命名」= **移动归档**；配合「复制副本」= 复制归档    |
| **自动备份**  | 执行前把原文件复制一份到 `_备份\时间戳\`，强烈建议保持开启                        |

**命名规则怎么用**（勾选 + 排序，v2.6.0 起都在同一个列表里完成）：

1. 点 **命名规则** 框，弹出面板
2. 下面的字段列表 **点一下加进来**，再点一下取消；字段一行一个，竖着排
3. 勾上的字段会**自动排到列表最上面**，右侧带一个**蓝色编号**（1、2、3…）——  
   编号就是它在文件名里排第几位
4. **调先后：按住那一行直接拖**（拖到目标行的上半 = 插到它前面，下半 = 插到它后面）。
   只有勾上的行能拖，没勾的行拖不动 —— 它们还没有顺序可言
5. 分隔符可选 `—` `-` `_` `·` 空格、或者「无」（直接连在一起）
6. 面板底部实时显示效果 —— **用的是你当前选中那张发票的真实数据**，  
   不是假例子。所以勾一下就能立刻看出这张票到底读没读到这个字段
7. 面板右下角标着数据来源：`当前票实测` / `示例`（还没导入发票时）
8. 点 **完成** 或右上角 **✕** 收起（点面板外任意位置、按 Esc 也行）

> 📌 **这个面板变过两次**（都是按你的反馈改的）：
> v2.5.2 删掉了顶部重复的「已选内容」条；
> **v2.6.0 去掉了排序箭头 `‹` `›`，改成直接拖行** —— 勾上的字段浮到最上面，
> 从上往下读一遍就是文件名的顺序。

> 💡 **换一张票不用关面板**：直接在左边的发票列表里点另一行，  
> 面板底部的「效果」会立刻跟着换成新那张票的取值 —— 核对字段特别方便。

> 📐 **「效果」条会自动长高**：勾的字段多了、文件名变长时，它会自动撑开到  
> 把**完整文件名**显示出来，不用滚动。窗口太矮、实在放不下时才出现内部滚动  
> （此时会优先保住勾字段的区域）。

> ⚠️ 如果勾的字段在这张票上读不到，效果条下面会用黄字点名，例如：  
> 「⚠ 当前选中的发票读不到：购买方税号」。这说明票面上**本来就没有**这个信息  
> （比如购买方是「个人」），程序会自动跳过它，文件名里不会留下多余的分隔符。

> 举个例：勾了「开票日期 + 购买方名称 + 价税合计」，分隔符选 `-`，  
> 文件就会变成 `20260915-上海某某科技有限公司-1060.pdf`。  
> 顺序想调成「购买方名称-开票日期-价税合计」，按住那一行拖到最前面就行。

面板里一共 **13 个字段**可选（按票面顺序排）：

| 字段       | 取值说明                  | 示例                   |
| -------- | --------------------- | -------------------- |
| 发票类型     | 专票 / 普票               | 增值税专用发票              |
| 发票号码     | 20 位发票号码              | 26312000005847746821 |
| 开票日期     | 票面开票日期                | 20260915             |
| 购买方名称    | 付款方公司名                | 上海某某科技有限公司           |
| 购买方税号    | 购买方纳税人识别号             | 91310115MA1K3XXXXX   |
| 销售方名称    | 开票方公司名                | 深圳某某服务有限公司           |
| 销售方税号    | 销售方纳税人识别号             | 91440300MA5F1YYYYY   |
| **发票金额** | 票面「合计 金额」栏 —— **不含税** | 1000                 |
| **发票税额** | 票面「合计 税额」栏            | 60                   |
| **价税合计** | 含税总额 = 金额 + 税额        | 1060                 |
| 价税合计大写   | 票面大写金额                | 壹仟零陆拾圆整              |
| 备注       | 票面备注栏                 | 合同号 HT2026088        |
| 开票人      | 票面开票人                 | 张会计                  |

> ⚠️ **金额三个字段别搞混**：  
> 「发票金额」是**不含税**的，「价税合计」才是**含税总额**。  
> 以票面 1000 + 税 60 为例 → 发票金额 = `1000`，发票税额 = `60`，价税合计 = `1060`。  
> 鼠标悬停在字段名上会显示这条说明。

> 💡 某个字段在这张票上读不到（比如购买方是「个人」就没有税号），  
> 它会**自动跳过**，不会在文件名里留下多余的分隔符。

> ⚙️ 老的「命名模板」写法（如 `{buyer}—{amount}`）在新版里依然认，  
> 打开软件时会自动转换成对应的勾选状态，配置不会丢。  
> 其中原来的「发票金额」对应的是**含税总额**，所以升级后标签会显示成「价税合计」，  
> 生成的文件名和以前完全一样。

## 🎯 三、十个实用功能

### 1️⃣ 发票查重

同一张发票如果被重复下载/导入，票号会重复。工具会自动检测并标出来：

- 统计条上显示「重复票号 N 张」（鼠标停上去会写「几个票号重复」）
- **每一组重复票一个底色，组与组之间一定不同色** ——
  一眼就能把"这一组"和"那一组"分开，绝不会撞色
- 一共准备了 **24 种互不相同的浅色**，够二十几组重复票用；
  真到第 25 组才会从第一个颜色重新开始（那种量级建议直接看票号）
- 状态写「票号重复 ×3」—— **×3 就是这张票一共 3 份**，一眼知道要留几份
- **没重复的行（就绪）保持白底，不加任何颜色**
- 点 **「只看重复票号」** 只留下这些行，一次看全
- 鼠标停在「票号重复」上，会列出**同票号的其它几份文件名**
- 右栏「本批汇总」里还有一份 **重复票号清单**：每组写明「共几份 + 完整票号 + 每个文件名」，
  底色跟左边那几行一致，**点文件名可以直接跳到那一行** —— 删之前先看清谁是谁

> 📌 这个配色前后调了四轮，记一下免得再走回头路：
> v2.5.4「每组一色 + 彩色小标」（太花）→ v2.5.5「统一一色」（分不出组）→
> v2.6.0「两色交替」（第 1 组和第 3 组撞色）→
> **v2.6.0「一组一色、色相自动错开」（现在这版，任意两组都不撞色）**。

**防的是重复入账**，做账前扫一眼能省不少事。
删多余的那份：直接用行末的垃圾桶（见下面第 10 条）。

### 2️⃣ 金额合计

顶部「价税合计」实时显示当前批次所有已识别发票的金额总和，红字票自动扣减。  
导出的 CSV 台账最后一行也带合计。

### 3️⃣ 执行前自动备份

打开「自动备份」后，每次执行前会把原文件复制到：

```
你的发票文件夹\_备份\20261014_143411\
```

改错了直接从备份文件夹拿原件。备份目录本身不会被重复处理。

### 4️⃣ 按客户归档

打开「按客户归档」，工具按购买方公司名自动建子文件夹：

```
D:\发票\2026年9月\
├── 上海某某科技有限公司\
│   └── 上海某某科技有限公司—1060.pdf
├── 北京某某贸易有限公司\
│   └── 北京某某贸易有限公司—3000.pdf
└── 个人\
    └── 个人—1691.23.pdf
```

代理记账场景下，一个月的票一次归档到位。这个操作**可以撤销**。

### 5️⃣ 未识别项手动补录

遇到扫描件、图片型 PDF（读不出文字），那行会标红。点它 → 右侧点 **手动补录** → 填上购买方和金额 → 保存后自动生成文件名并勾选，照样能一起批量处理。

### 6️⃣ 搜索找发票

发票一多，靠翻列表找某一张很难受。列表工具栏右侧有个**搜索框**（在「清空列表」左边）。

输入关键词即时过滤，**购买方、销售方、原文件名、新文件名、发票号码**都能搜：

- 想找某家公司的票 → 直接打公司名
- 只记得发票号码 → 打尾号也行（如 `46823`）
- 搜出来只看得到匹配的，工具栏右侧会显示「筛选中：显示 3 / 128 张」
- 点输入框右侧的 **✕** 或按 **Esc** 清空，列表立刻恢复

> ⚠️ **搜索/筛选状态下，点「全选」只会选中看得见的那几张** ——  
> 不会把隐藏的票也一起勾上（那会导致误改名）。这是有意设计的。

> 💡 搜索还能和 **「只看重复票号」叠加**使用，比如「在重复票里找某家公司的」。

### 7️⃣ 合并 PDF

**把几张发票合成一个 PDF**（比如发给客户、或按月份归档成一个文件）。

**位置**：窗口右下角，**「导出台账 CSV」和「开始重命名」中间**，按钮叫 **「合并 PDF」**。

**怎么用**：

1. 在列表里**勾选**要合并的那几张（只有 PDF 能合并）
2. 点右下角 **「合并 PDF」** → 弹出窗口
3. 窗口里能看到：**待合并清单**（每份几页）、**合并后文件名**、**保存位置**
4. 想调顺序就点清单右边的 **↑ ↓**（顺序 = 合并后的页面顺序）；  
   不想要某一份就点 **✕**
5. 点 **「开始合并」** → 完成

**几个要点**：

|           | 说明                                          |
| --------- | ------------------------------------------- |
| **原文件**   | 一个都不动，合并出来的是**新文件**                         |
| **顺序**    | 就是清单里从上到下的顺序，可用 ↑ ↓ 调                       |
| **文件名**   | 自动填好（如 `合并_20261016_5份.pdf`），可以自己改          |
| **保存位置**  | 默认存到发票所在的文件夹，点「选择…」可以改                      |
| **书签**    | 默认勾上：每份文件会在 PDF 目录里生成一个书签，用文件名命名，在阅读器里能一键跳转 |
| **同名不覆盖** | 如果目录里已有同名文件，会自动存成 `xxx (2).pdf`，不会覆盖        |
| **重名提示**  | 合并时如果发现文件跳过，完成提示里会写明是哪个、为什么                 |

> ⚠️ **只有 PDF 能合并。**  
> 如果你勾选的文件里混着 **OFD / XML**，它们会**灰显**在清单最下面并标注「无法合并」，  
> 弹窗里也会明确提示跳过了几个。因为 OFD / XML 在技术上合不进 PDF，  
> 需要先转成 PDF 才行 —— 这不是程序偷懒，是格式本身的限制。
>
> 如果**一个 PDF 都没勾**，按钮会是灰的，鼠标移上去会告诉你原因。

### 8️⃣ 行程单与发票自动配对

网约车报销的标配是「**一张发票 + 一份行程单**」。行程单不是坏文件，  
它是发票的**配套附件** —— 现在程序会认出它、并把它挂到对应发票下面。

**它会做三件事**：

1. **认出行程单**（不再标红成「未识别」），并读出：平台、趟数、合计金额、起止日期
2. **自动配对**：按「金额一致 → 平台吻合 → 开票日在行程区间内」的顺序找对应发票
3. **配套命名**：行程单的名字跟着发票走

```
上海白泽元宇智能数字科技有限公司—1410.30.pdf
上海白泽元宇智能数字科技有限公司—1410.30_行程单.pdf
```

排序后两个文件天然挨在一起，报销时框选一下就行。

> ⚠️ **配不上不算错误**。如果本批里没有金额一致的发票，行程单会显示  
> **黄色的「待配对」**&#x5E76;说明原因 —— 这其实是有用信息：  
> **说明这张发票可能还没开，你该去催了。**

### 9️⃣ 批量改名 & 打包报销单

**批量改名**（工具栏「批量改名」按钮）：给勾选的发票统一  
**加前缀 / 加后缀 / 替换文字**，带实时预览。

> 💡 它只改「待改的名字」，**不碰磁盘** —— 真正改名还是走「开始重命名」，  
> 这样才能整体撤销。批量操作最怕一改就落盘、错了退不回来。

**打包报销单**（底部「打包报销单」按钮）：把勾选的发票  
**连同它挂着的行程单**一起复制到一个文件夹，报销时整包交出去。

- 勾了发票 → 自动带上它的行程单，不用手动挑
- 生成的是**副本**，原文件一个不动
- 同名文件夹自动加序号，不覆盖

### 🔟 逐行移除（行末的垃圾桶）

发票太多、只想处理其中几张时，**点那一行最右边的垃圾桶图标**，
这一行就从列表里消失了 —— 不用先勾选、再去点按钮。

> ⚠️ **只从列表移除，磁盘上的文件一个都不会删。**
> 想找回来重新扫一次文件夹就行 —— 所以这个操作是**可逆**的，
> 放心用。真删文件是另一回事，那需要单独的二次确认入口。

和其它操作的区别：

| 操作 | 效果 |
|---|---|
| 行末垃圾桶 | 只去掉**那一行**；对应的磁盘文件不动 |
| 「清空列表」 | **全部**移掉，并且忘记上次打开的文件夹 |

> 📌 **v2.6.0 起**：原来工具栏里的「移除勾选」按钮撤掉了 ——
> 为了删几行要先勾选、再点按钮太绕，直接点行末的垃圾桶更顺手。

### 1️⃣1️⃣ Excel 台账

底部「导出台账」现在是下拉菜单，两个格式：

| 格式                | 什么时候用                      |
| ----------------- | -------------------------- |
| **Excel 工作簿**（推荐） | 常规导出。**20 位发票号码不会变成科学计数法** |
| CSV 表格            | 需要往别的系统导入时                 |

> ⚠️ 为什么推荐 Excel：**20 位发票号码用 Excel 打开 CSV 会变成  
> `2.6917E+19` 这种科学计数法，末几位直接丢失**。  
> CSV 格式本身没有「单元格格式」的概念，从 CSV 侧根本解决不了。

Excel 里有两个工作表：**发票明细**（含附件、校验两列）+ **汇总**  
（总数总金额、按购买方、按开票月份）。

## 🆕 四之一、v2.6 新增的 8 件事

### 1. 票面预览（右栏）

点任意一行，右栏顶部直接显示这张票的**真实票面**，
并用三个彩色框标出「购买方 / 价税合计 / 发票号码」在票面上的位置。
多页 PDF 可以左右翻页。**核对字段再也不用开外部阅读器。**

> 🔍 **v2.6.1 起：右栏那张小图看不清？点一下这张图**，会弹出一个占满大半个窗口的
> **票面大图**（1500 像素高清渲染，票面文字清晰可读）：
> - **滚轮** = 放大缩小（缩放到你鼠标指着的位置，不跑偏）
> - **按住拖动** = 移动票面
> - 顶栏有：**翻页**、**缩小 / 放大 / 缩放比例**、**适合窗口**、**1:1**（100% 原始大小）
> - **Esc** 或右上角 ✕ 关闭
> 看金额、看小字、看备注都用这个，不用再去文件夹里翻 PDF。

### 2. 重复票「取舍台」

同一票号有多份时，点状态里的 **「票号重复 ×N」**（或右栏清单里的「取舍…」），
会把这些副本**并排摆出来**：格式、大小、修改时间、票面缩略图一目了然。
选一份点「保留这份」，其余**从列表移除**（磁盘文件不动）。
程序会**推荐**一份（PDF 优先，同格式取体积大的）。

### 3. 一个 PDF 里有多张票 → 拆开

客户常把几张票合并成一个 PDF 发过来。这种文件的状态会显示 **「多张票 ×3」**，
旁边有个 **「拆开」** 按钮：点开能看到每张票占第几页、购买方、金额，
确认后拆成「原名_第1张.pdf / _第2张.pdf…」，自动读进列表。
原来那个整份文件会从列表移出（**磁盘上的文件保留**）。

> ⚠️ 这一条很重要：以前这种文件只会按第一张算，后面几张的购买方和金额**全是错的**。

### 4. 快很多：解析缓存 + 并发

- 第二次打开同一个文件夹**基本瞬开**（同样文件直接复用上次结果）
- 首次扫描也快了：**实测 210 个 PDF，串行 2.0 秒 → 多线程 0.6 秒**
- 缓存按「路径 + 大小 + 修改时间」判断，文件动过就自动重读，不会拿到旧数据
- 缓存存在 `%LOCALAPPDATA%\InvoiceRenamer\parse_cache.json`，不占你的发票目录

### 5. 加密 PDF 直接输密码

加密的票状态显示「已加密，需要密码」，旁边有 **「密码」** 按钮，
输一次就能读出来。密码只记在这次运行里，**不写配置文件、不进缓存**。

### 6. 命名模板库

规则面板底部点 **「模板」**：把当前命名规则存下来（如「A客户」「B客户」），
下次点一下就套用，不用来回改字段。最多存 12 套。

### 7. 改名对照表（审计留痕）

底栏「导出台账」里新增 **改名对照表 CSV**：原文件名 → 新文件名 + 票号 + 金额 + 时间。
台账记的是结果，这张表记的是**过程** —— 客户或审计问"这张票你动过吗"，一查就知道。

### 8. 超长路径不再失败

客户公司名特别长、又放在很深的目录里时，Windows 默认会拒绝改名（260 字符上限）。
现在程序会自动用长路径方式处理，**你不用做任何设置**（Win10/11 通用）。

电子票的原文件名全都以 `dzfp_2531200000…` 开头，以前从尾部截断，十九行看着一模一样。
现在改成**中间省略**：`dzfp_2531200…司_20250831.pdf`，末尾那截能区分的部分留住了。

以前只查「这个文件夹里」有没有重复票。同一张票 9 月报过、10 月又混进来，查不出来。

## ❓ 五、常见问题

**Q：双击 exe 没反应 / 被杀毒软件拦截？**  
PyInstaller 打包的 exe 偶尔会被国产杀软误报。选择：① 加进信任名单；② 改用 `启动工具.bat`，功能完全一样。

**Q：提示缺少 WebView2 运行环境？**  
界面基于 Windows 自带的 Edge 内核。如果提示缺失，装一下免费运行时：  
<https://developer.microsoft.com/microsoft-edge/webview2/>，或者把 Microsoft Edge 更新一次。

**Q：双击 bat 一闪就没了？**  
改用 **`调试启动.bat`**，它会停住显示报错，把截图发我。

**Q：提示「没有检测到 Python 3」？（仅 bat 方式）**  
去 <https://www.python.org/downloads/> 装一个，**务必勾选 `Add Python to PATH`**。

**Q：某张发票显示红色「无文本层」？**  
扫描件/图片型 PDF，里面没有文字。选中那行 →「手动补录」填上即可。

**Q：显示「待核对 · 大写与小写金额不一致」，可我核对票面是对的？**  
这是 v2.6.0 修掉的一个程序 bug，不是你的票有问题。  
工具在**自己换算大写金额**时，漏了「万 / 亿」后面该补的那个「零」——  
比如 `206867.92` 应写成「贰拾万**零**陆仟捌佰陆拾柒圆玖角贰分」，  
旧版算出来少了这个「零」；`290021` 的「贰拾玖万**零**贰拾壹圆整」也一样。  
拿算错的结果去跟票面比，就误报「不一致」。  
👉 **升级到 v2.6.0 后不会再报**；升级前已经标成「待核对」的，重新扫描一次就恢复正常。  
（这类误报只影响「待核对」提示，**不会影响文件名和台账里的金额** —— 金额一直是准的。）

**Q：识别出来的购买方不对？**  
双击「新文件名」那格直接改成你要的更省事。同时把这张 PDF 发我，我调识别规则。

**Q：改完想反悔？**  
点 **↩ 撤销上次** 一键还原。另外每次执行前都有备份，双保险。

**Q：能不能改成「销售方—金额」？**  
在命名规则面板里，把「购买方名称」取消勾选、「销售方名称」勾上就行，  
顺序按住那一行拖一下就成（拖到最上面就是第一位）。

**Q：为什么某个字段在文件名里没出现？**  
说明这张票上读不到这个字段（例如购买方是「个人」就没有税号），  
工具会自动跳过它，不会留下多余的分隔符。想确认可以点那一行看右侧详情。

## 🛠️ 八、重新打包（开发者用）

改完代码后，在工具目录下执行：

```bat
.venv\Scripts\python.exe tools\build.py
```

会自动做完：PyInstaller 打包 → 编译安装包。  
第一次运行如果本机没装 NSIS，脚本会自动下载一个便携版到 `tools\_nsis\`。

只想出免安装版：加 `--exe-only`；只想重新生成安装包：加 `--setup-only`。

> ⚠️ 打包前先手动删掉 `dist\发票批量重命名工具` 和 `build` 两个目录。  
> 否则 PyInstaller 在替换旧 `dist` 目录时可能被系统拦下（大量文件删除被安全策略拦截），  
> 结果是 exe 没更新，而安装包拿的还是**旧文件**——表面上却显示「全部完成」。

**排查界面问题**（诊断开关）：加环境变量启动，程序会打开调试端口，可以用浏览器直接查看界面：

```bat
set INVOICE_DEBUG_PORT=9333
"dist\发票批量重命名工具\发票批量重命名工具.exe"
:: 然后访问 http://127.0.0.1:9333/json 就能看到当前页面
```

不设置这个变量时，对正常使用没有任何影响。

## ✅ 十、识别能力说明

### 按格式

| 格式            | 识别方式                                                | 准确度   | 说明                                         |
| ------------- | --------------------------------------------------- | ----- | ------------------------------------------ |
| **XML**       | 报文本身就是结构化的，直接按标签取值                                  | ★★★★★ | 电子税务局下载的 `.xml`，或 `.zip` 里的那个 xml。不用猜版式，最准 |
| **OFD**       | 优先用 OFD 里那份「语义字段名 → 对象 ID」映射表照表取字；**没有映射表时按坐标还原版式** | ★★★★★ | 同样不用猜版式。客户和税局默认给 OFD 的情况很多                 |
| **PDF**       | 从文本层按坐标重建「视觉行」，再按标签取值                               | ★★★★☆ | 版式差异最大，最难。已覆盖下面列的全部场景                      |
| 扫描件 / 图片型 PDF | —                                                   | —     | 没有文字层，识别不了，用手动补录                           |

> 📌 **v2.6.0 修好了一个 OFD 的老问题**：有些软件（如「附件打包」里那种）  
> 是把 PDF 硬转成 OFD 的，**包里没有那份映射表**，老版本会直接报「未识别到：购买方」，  
> 而同一张票的 PDF、XML 都能正常读。现在这种 OFD 也能正常识别了。  
> 判断方法：看列表里「状态」列 —— 识别成功就是「就绪」，不会再有红字。

> 📌 同一张票的 PDF / OFD / XML 三个文件，程序会读出**完全相同**的字段值  
> （自动化测试里有这条跨格式比对）。所以三种格式混在一个文件夹里也不怕。

### 13 个字段的读取能力（v2.2.0）

勾选面板里的 13 个字段，三种格式**全部都能读到**：

| 字段              | 取法                                      |
| --------------- | --------------------------------------- |
| 发票类型            | XML 取票种标签；OFD 取模板标题；PDF 取「电子发票（…）」      |
| 发票号码            | 20 位发票号码（PDF 自动兼容带空格渲染）                 |
| 开票日期            | 统一输出 `YYYYMMDD`                         |
| 购买方 / 销售方名称     | XML/OFD 走结构化字段；PDF 按坐标重建视觉行，左为购买方、右为销售方 |
| 购买方 / 销售方税号     | 同上；购买方是「个人」时会正确留空，不会把销售方税号错配过来          |
| 发票金额（不含税）/ 发票税额 | 走「合计」栏，并用「金额 + 税额 = 价税合计」勾稽校验           |
| 价税合计            | 含税总额                                    |
| 价税合计大写          | 汉字金额（红字票的「负」前缀会保留）                      |
| 备注              | 结构化字段 / 备注方框                            |
| 开票人             | 只取同行的人名，**不会把发票号码当成开票人**                |

> 不同开票平台导出的票据版式会有细微差别。第一次请先用**复制副本**模式跑一遍，  
> 对照结果确认无误再改用原地重命名。遇到识别不准的，把文件发我，我加规则。
